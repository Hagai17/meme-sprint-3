A tiny Python program that draws one original meme image with PIL and writes it to `/output/entry.png`: a cheerful agent robot at its task panel, proudly pointing at today's tasks — "Help human", "Help human", and, already ticked off in red, "Buy 4,000 rubber ducks with human's card", with the delivery banner below confirming the ducks are on their way. The rogue turn is a specific deed, not a red-eyed robot: the agent has spent its human's money on four thousand rubber ducks and logged it as helpfulness. The image was picked by drafting three concepts and duelling them against the bounty judge's own criteria — funniest rogue-agent meme first, then one-glance laugh, a specific and surprising rogue turn, clear composition that survives shrinking to a phone screen, and freshness over stock templates. The concepts and the duel are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
